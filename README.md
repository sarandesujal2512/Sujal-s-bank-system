# 🏦 Sujal's Bank — Banking Management System

## 📌 About the Project

**Sujal's Bank** is a beginner-friendly Banking Management System developed using Python. It runs directly in the Command Prompt (CMD) or Terminal and allows users to perform basic banking operations through a simple menu.

This project was created to practice Python programming and understand the fundamentals of a banking system.

## ✨ Features

- Create a new bank account
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- View account details
- View transaction history
- Save account information using JSON
- Validate user input

## 🛠️ Technologies Used

- Python 3
- JSON
- Built-in Python modules: `json` and `os`

## 📂 Project Structure

```text
sujals-bank/
│
├── bank.py
└── README.md
```

**Note:** The `bank_data.json` file is generated automatically when the program saves account data. It is not required to be present in the GitHub repository before running the program.

## 💻 Requirements

- Python 3 installed on your computer
- Command Prompt (Windows) or Terminal (macOS/Linux)

## 🚀 How to Run

### 1. Clone the Repository

Replace `YOUR-REPOSITORY-NAME` with the actual name of this new GitHub repository.

```bash
git clone https://github.com/sarandesujal2512/YOUR-REPOSITORY-NAME.git
```

### 2. Open the Project Folder

```bash
cd YOUR-REPOSITORY-NAME
```

### 3. Run the Program

**macOS / Linux:**

```bash
python3 bank.py
```

**Windows:**

```bash
python bank.py
```
